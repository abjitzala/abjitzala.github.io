HoneyDoom

Lead Graphics Programmer | C++, Direct3D 11, ImGui | Team of 5 2023

A custom 3D component-based game engine built with C++, Direct3D 11 and ImGui. Play as a honeydew exploring a dungeon full of enemy melons, avoiding obstacles, collecting items, and reaching the end.

Responsibilities

  • Architected and built the 3D graphics engine from scratch.
  • Implemented toon shading, deferred shading, shadow mapping, and background fade.
  • Incorporated a sky-sphere using cube mapping and added debug drawing for colliders.
  • Created a GPU-based particle system using a geometry shader that supports a large number of particles.

Level editor

  • Integrated the Gizmos API for drag-and-drop level editing.
  • Added text rendering to show each game object's name in the scene.
  • Implemented click-to-select for game objects using ray casting (picking).
