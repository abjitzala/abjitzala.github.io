Skeletal Animation & Path Following

Independent project | C++, Direct3D 11 2022

Implemented skeletal animation and skinning (up to 96 bones). An animated model walks along a curved path at a constant speed and with the correct orientation.

An ease-in/ease-out distance-time function is used for path following and animation at the beginning and end of the path.
